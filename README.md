# 时间轴日记 (Timeline Diary)

Obsidian 插件 — 将文本时间轴自动转化为可视化时间分配图，支持日/周/月多维度视图。

## 功能

- **时间轴色块条**：在日记中编写 `timeline` 代码块，自动渲染为 24 小时色块条
- **周/月统计视图**：汇总日记文件夹中的所有时间记录，按周/月展示时间分配
- **自定义分类**：支持自定义事件类型和对应颜色，使用 `#标签` 标记

## 使用方法

### 1. 在日记中插入时间轴

````markdown
```timeline
08:00 - 12:00 工作内容 #工作
12:00 - 13:00 午休 #生活
14:00 - 18:00 学习新知识 #学习
20:00 - 22:00 看电影 #娱乐
```
````

### 2. 查看统计

- 命令面板（Ctrl+P）→ "打开时间统计"
- 支持周视图和月视图切换

### 3. 日记文件命名

统计视图通过文件名提取日期，支持以下格式：

| 格式 | 示例 |
|------|------|
| 带分隔符 | `2026-06-07`, `26.6.7`, `2026_06_07` |
| 8位紧凑 | `20260607` |
| 6位紧凑 | `260607`（文件名纯数字） |

## 安装

### 通过 Obsidian 社区插件（推荐）

1. 打开 Obsidian → 设置 → 第三方插件
2. 关闭安全模式
3. 浏览社区插件，搜索"时间轴日记"
4. 安装并启用

### 手动安装

1. 下载 `main.js`, `manifest.json`, `styles.css`
2. 放入 vault 的 `.obsidian/plugins/timeline-diary/` 目录
3. 在 Obsidian 中启用插件

## 设置

- **日记文件夹**：存放日记文件的文件夹路径
- **代码块标识**：用于识别时间轴的代码块语言（默认 `timeline`）
- **事件类型**：自定义事件类别及颜色
- **未分类颜色**：无标签条目的默认颜色

## 开发

```bash
npm install
npm run dev    # 开发模式（热更新）
npm run build  # 生产构建
```
